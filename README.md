# `Mistral-Large-3-675B-Instruct-2512-BF16` Serving on TPU `v7x` with `vllm-torchtpu`

Multi-host deployment manifest, OpenAI SSE streaming benchmark harness (`c=1..256` concurrency, `32K`–`128K` context, and greedy `natural-chat`), and latency/throughput results for unquantized **[`mistralai/Mistral-Large-3-675B-Instruct-2512-BF16`](https://huggingface.co/mistralai/Mistral-Large-3-675B-Instruct-2512-BF16)** (`675B` total / `41B` active parameters, `1,352.0 GB` / `1.23 TiB` BF16 across `272` consolidated safetensors shards) on a **single TPU `v7x-16` slice (`2x2x4`, 16 chips / 32 TensorCores, `3,072 GiB` HBM3e)** with **`vllm 0.32.0` + `vllm-torchtpu` + `TorchTPU 0.2.0` GA**.

## 2. Benchmark Results (`v7x-16` Pure BF16 vs FP8 at `TP=2, DP=16, EP=32`)

TPU `v7x-16` provides `3,072 GiB` HBM3e (`118 TB/s` aggregate HBM bandwidth), enabling the entire `1.35 TB` unquantized BF16 checkpoint to run on a single 16-chip slice at `132,096` max context with `12.26M` FP8 MLA KV-cache tokens and zero failed requests across all `11` suites (`0` errors out of `1,028` requests):

- **High-Throughput Batching (`4,096` in / `1,024` out, `c=1..256`):** Unquantized BF16 scales cleanly to **`3,156.49` output tok/s (`15,785.51` total tok/s)** at `c=256`, achieving `82.8%` of native FP8 throughput (`3,812.96` output tok/s) despite reading `2×` larger BF16 expert weights per decode step (`39.75` stream tok/s and `25.17 ms` median TPOT on single-stream greedy decode).
- **`128K` Long-Context Crossover (`131,072` in / `512` out, `c=4`):** At `131,072` input context (`1.05M` prefill tokens per batch), unquantized BF16 reaches **`2,940.83` total tok/s (`11.44` output tok/s, `31.31` stream tok/s)**, outperforming `ml3-fp8-tp2-dp16-ep32-fp8kv` (`2,650.90` total tok/s / `10.31` output tok/s) by **`+10.9%`** because native BF16 avoids dynamic per-group (`group_size=128`) input activation quantization overhead across `131K`-token prefill sequences.

## 3. Repository Structure & Reproduction

- [`docker/Dockerfile`](./docker/Dockerfile) — `vllm 0.32.0` + `vllm-torchtpu` + `TorchTPU 0.2.0` GA + `SemiAnalysisAI/InferenceX@f6c1f5b5`
- [`scripts/run_tpu_benchmark_sweep.py`](./scripts/run_tpu_benchmark_sweep.py) — Async OpenAI SSE streaming benchmark (`concurrency_<in>in`, `cached_<ratio>pct_prefix`, `context_sweep`, `greedy_natural`)
- [`scripts/stage_hf_to_gcs.py`](./scripts/stage_hf_to_gcs.py) — Parallel `272`-shard Hugging Face -> GCS stager
- [`k8s/v7x-16-ml3-bf16-tp2-dp16-ep32.yaml`](./k8s/v7x-16-ml3-bf16-tp2-dp16-ep32.yaml) — GKE LeaderWorkerSet (`4` hosts × `4` chips = `32` TensorCores, `TP=2, DP=16, EP=32`) + Benchmark Job
- [`results/`](./results/v7x-16-2x2x4-32cores__mistralai__Mistral-Large-3-675B-Instruct-2512-BF16__ml3-bf16-tp2-dp16-ep32-fp8kv__20261103T070908Z/REPORT.md) — Raw Markdown & JSON benchmark artifacts

```bash
# 1. Stage mistralai/Mistral-Large-3-675B-Instruct-2512-BF16 (1.35 TB, 272 shards) to GCS
python3 scripts/stage_hf_to_gcs.py --repos mistralai/Mistral-Large-3-675B-Instruct-2512-BF16 --bucket YOUR_GCS_BUCKET --prefix models

# 2. Deploy Benchmark Driver ConfigMap and LeaderWorkerSet + Benchmark Job on TPU v7x-16 (2x2x4)
kubectl create configmap tpu-bench-script --from-file=run_tpu_benchmark_sweep.py=scripts/run_tpu_benchmark_sweep.py
kubectl apply -f k8s/v7x-16-ml3-bf16-tp2-dp16-ep32.yaml
```
